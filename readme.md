# Learn2Earn - VidGenz

**Learn2Earn Platform** — A revolutionary Web3 + AI platform where users earn rewards while learning new skills.

Live Demo: [https://learn2earn-ivory.vercel.app](https://learn2earn-ivory.vercel.app)

---

## ✨ Features

- Earn cryptocurrency rewards by completing courses and quizzes
- AI-powered personalized learning paths
- Smart contract-based reward distribution
- User progress tracking and certificates
- Modern and responsive UI
- Full-stack architecture (Frontend + Backend + Blockchain)

---

## 🛠 Tech Stack

- **Frontend**: Next.js / React + JavaScript
- **Backend**: Node.js / Express
- **Blockchain**: Solidity + Hardhat / Thirdweb
- **AI/ML**: Integration for personalized learning
- **Database**: MongoDB / PostgreSQL
- **Deployment**: Vercel + Docker

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/monickark-web3/learn2earn.git
cd learn2earn
```

### 2. Go to main project
```bash
cd learn2earn-ai
```

### 3. Run using Docker (Recommended)
```bash
docker-compose up --build
```

### 4. Or Run Manually
```bash
# Terminal 1 - Backend
cd server && npm install && npm run dev

# Terminal 2 - Frontend
cd client && npm install && npm run dev
```
